# 11 — Export System Upgrade

## Current State
- Single CSV export via `exportUtils.ts`
- Export button in analytics header (recently wired up)

## Target: ZIP + PDF

### ZIP Export (Multiple CSVs)
When user clicks download, generate a ZIP containing:
- `overview.csv` — KPI summary (metric, value, change%)
- `traffic.csv` — Daily traffic data (date, users, sessions, pageviews, bounce, duration)
- `pages.csv` — Top pages (path, views, bounce, avg_time)
- `referrers.csv` — Traffic sources (source, sessions, users)
- `countries.csv` — Geographic data (country, users, sessions)
- `devices.csv` — Device/browser/OS breakdown
- `keywords.csv` — Search Console queries (if connected)

**Library:** `jszip` (client-side ZIP creation)
```bash
npm install jszip
```

**Flow:**
1. User clicks download icon in analytics header
2. Dropdown: "Export CSV" | "Export ZIP" | "Export PDF"
3. ZIP: generate all CSVs, bundle with JSZip, trigger download
4. Include README.txt with date range and filters applied

### PDF Report
Branded analytics report with:
- TrafficClaw logo header
- Date range + site name
- KPI summary cards
- Traffic trend chart (rendered as PNG via html2canvas)
- Top 10 pages table
- Top 10 sources table
- Geographic breakdown
- Footer: "Generated by TrafficClaw — trafficclaw.com"

**Library:** `jspdf` + `html2canvas`
```bash
npm install jspdf html2canvas
```

**Flow:**
1. Render report sections in a hidden div
2. Capture each section as canvas
3. Add to PDF pages
4. Download
